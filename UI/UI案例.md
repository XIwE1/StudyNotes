### 侧边栏设计
**选中态永远是「底 + 指示条 + 文字提亮」三者组合**，只改文字颜色在暗色下辨识度不够。
凹槽 = 轨道比容器暗、滑块比轨道亮，这套「深槽 + 亮块」在暗色下辨识度最高。

![alt text](image-9.png)

可以用color-scheme 让系统去处理 滚动 表格等能让系统配置的暗夜模式

### 视差滚动
使不同层次的元素以不同的速度进行滚动，创造出一种三维的视觉深度感。这种技术可以增强用户体验，使网页内容更加生动有趣。

background-attachment 和 transform:translate3D

### 过度动画

不要在高频的场景加入位移过多的 显眼的动画

核心理由：

**高频切换场景下，半秒级过渡会累积成真实等待；**

**不冗余** 选中态已提供足够导航反馈；

动画要表达真实的空间/因果/层级关系

**频率主导** 低频落地页动画可以营造仪式感；**高频切换必须低延迟、低干扰。交互越频繁，动效越应克制**
