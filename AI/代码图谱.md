# 代码图谱

**节省 Token、提升效率**

传统方式致力于教人读懂代码，AI 时代需要“代码地图”。

上下文有限

提前回答关于代码结构的关键问题（有哪些模块，影响范围，业务流转）

## 相关技术



### 代码图谱类
CodeGraph
为 Agent 服务的本地结构化查询数据库（少读代码 少调用工具）
代码索引成SQLLite数据 + MCP + 本地运行
文件监听自动同步

Code Review Graph
与上文类似，适合接 CI 评审流程，对个人使用偏重

GitNexus
适合monorepo等项目 全局视野和多仓库支持

### 知识文档类
Understand Anything
输入：代码、文档
生成的可交互代码库讲解 - **知识图谱**，**给人看**
Tree-sitter + LLM + 多 Agent（烧token）

Graphify 
输入：代码 md 图片 pdf
研究者、开发者、知识库管理者，构建长期知识库
纯静态分析（tree-sitter AST），构建过程不用 LLM

## 原理
AST 抽象语法树
MCP 外部工具调用
文件摘要、架构层级、业务域分析

**Tree-sitter**
1. 为知识图谱的查询提供 **节点**（函数、类） 和 **边**（调用、导入）
2. 一个 **解析器** 生成工具 和 **增量解析库**

作用：
1. 把源代码文本**转换**成计算机能理解的结构化数据——语法树，**CST**（具体语法树）

原理：
1. 根据编程语言的语法定义生成一个解析器程序 - **“结构提取引擎”**
2. 增量解析，更新不会重新解析，只针对受影响部分
